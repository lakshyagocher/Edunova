I'm confused about the section formula. If A(2,3) and B(6,7) are two points and P divides AB in ratio 1:3 internally, how do I find P's coordinates?
💬 4 answers👁️ 130 views
EN
EduNova Expert Owner
The Section Formula for internal division: P(x,y) = ((m₁x₂ + m₂x₁)/(m₁+m₂), (m₁y₂ + m₂y₁)/(m₁+m₂))

Given A(2,3), B(6,7) and ratio 1:3:
x = (1×6 + 3×2)/(1+3) = (6+6)/4 = 12/4 = 3
y = (1×7 + 3×3)/(1+3) = (7+9)/4 = 16/4 = 4

So P = (3, 4) ✅

📷

Uploaded image: textbook_page_SN1_SN2.jpg

💬 2 answers👁️ 88 views

Sanya Patel Class 12 Student
SN1: Two-step, carbocation intermediate, favours tertiary substrates, unimolecular (rate depends on substrate only).
SN2: One-step, inversion of configuration (Walden inversion), favours primary substrates, bimolecular (rate depends on both substrate and nucleophile).

Quick memory tip: SN1 = Slow/Stable carbocation. SN2 = Speedy backside attack! ⚡

How do I evaluate lim(x→0) [sin(x)/x]? I know the answer is 1 but I don't understand why. Can someone show me a proper proof?
💬 5 answers👁️ 210 views
EN
EduNova Expert Owner
We use the Squeeze Theorem (Sandwich Theorem):

For 0 < x < π/2, we can geometrically prove: cos(x) ≤ sin(x)/x ≤ 1

Since lim(x→0) cos(x) = 1 and lim(x→0) 1 = 1,
By Squeeze Theorem: lim(x→0) sin(x)/x = 1 ✅

This is a standard limit you should memorize — it's used constantly in calculus!

What is the difference between "fewer" and "less"? I keep getting confused about when to use which one.
💬 3 answers👁️ 156 views
EN
EduNova Expert Owner
Simple rule: Fewer = countable nouns | Less = uncountable nouns

Examples:
✅ "I have fewer books" (books are countable)
✅ "I have less water" (water is uncountable)

Trick: If you can add a number before it (5 books, 3 students), use fewer. If you can't (5 waters ❌), use less.
